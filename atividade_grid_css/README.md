# Catálogo Responsivo — GRID CSS

Atividade de website responsivo usando HTML e CSS Grid.

## Estrutura

- `index.html`: conteúdo do site, menu, produtos, categorias e rodapé.
- `style.css`: estilos, layout com Grid CSS, media queries e menu hamburger mobile.

## Recursos implementados

- Layout responsivo com CSS Grid.
- Grade de produtos com imagens e textos.
- Menu de navegação convertido em menu hamburger no mobile.
- Seção de categorias.
- Rodapé com informações de contato.

## Executar

Abra `index.html` desta pasta no navegador. Não há dependências para instalar. As imagens externas do Unsplash precisam de conexão com a internet para carregar.

A atividade foi movida para esta pasta mantendo o HTML e o CSS originais. O `index.html` da raiz do repositório redireciona para esta página.
